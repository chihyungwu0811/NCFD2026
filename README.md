# 2026 全國計算流體力學會議網站

這是一個可直接部署至 GitHub Pages 的單頁式網站。

## 部署方式

1. 在 GitHub 建立新的公開 Repository，例如：
   `2026-cfd-conference`
2. 將本資料夾中的所有檔案上傳到 Repository 根目錄：
   - `index.html`
   - `.nojekyll`
3. 進入 Repository 的：
   `Settings` → `Pages`
4. 在 `Build and deployment`：
   - Source 選擇 `Deploy from a branch`
   - Branch 選擇 `main`
   - Folder 選擇 `/ (root)`
5. 按下 `Save`。
6. GitHub 完成部署後，網站網址通常會是：
   `https://你的GitHub帳號.github.io/2026-cfd-conference/`

## 更新網站

直接修改或重新上傳 `index.html`。GitHub Pages 會在提交後自動重新部署。

## Google 協作平台嵌入

取得 GitHub Pages 公開網址後，在 Google 協作平台選擇：

`插入` → `嵌入` → `依網址`

貼上 GitHub Pages 網址即可。
